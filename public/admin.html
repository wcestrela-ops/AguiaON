Finanças & Gateways

Mercado Pago (Split & Pagamentos)

Conta própria da plataforma (não a de cada lojista) — usada quando a AguiaON cobra as empresas pelo uso do sistema (billing da plataforma).

Gere em mercadopago.com.br/developers → sua aplicação → Credenciais de produção. A Comissão da Plataforma abaixo é o % retido automaticamente nos pagamentos dos clientes finais, quando o split estiver ativo.

Mercado Pago — OAuth de Lojistas (PIX)

Permite que lojistas conectem suas contas MP para receber pagamentos PIX. Obtenha em mercadopago.com.br/developers → seu app → Credenciais de produção.

Asaas (Cobranças Automáticas)

Conta própria da plataforma no Asaas — usada como método de cobrança do billing da plataforma quando o Mercado Pago não estiver configurado (funciona como fallback entre os dois).

Gere a API Key em asaas.com → Integrações → Chave de API. O Wallet ID fica em Configurações → Conta.

Bancos & PIX (Informações de Exibição)

Texto livre, só para exibição — não gera cobrança nem integra com nada. Aparece como referência bancária/PIX da plataforma em telas ou comunicações que precisem mostrar seus dados de recebimento.

Motores de IA (Global Keys)

Provedor Primário (fallback automático se falhar)

Essas chaves alimentam a Ágata (assistente de IA) e outras automações do sistema. Preencha só os provedores que for usar — o Provedor Primário acima é tentado primeiro; se faltar chave ou a chamada falhar, cai automaticamente pro próximo configurado.

🖥️ IA Local (Ollama) — Prioridade

Servidor Ollama próprio (auto-hospedado, sem custo por chamada). Rode ollama serve e informe a URL acessível pelo servidor da AguiaON — não use localhost se o Ollama estiver em outra máquina/container.

Gere grátis em aistudio.google.com/apikey.

⚡ Groq Cloud Key

Inferência rápida e gratuita até certo limite. Gere em console.groq.com/keys.

🤖 OpenAI Key

Pago por uso. Gere em platform.openai.com/api-keys (precisa de créditos na conta).

Pago por uso. Gere em console.anthropic.com → API Keys.

WhatsApp, PWA & E-mail

Evolution API (WhatsApp)

Servidor Evolution API (auto-hospedado) que conecta o sistema ao WhatsApp — base pra automações de mensagens dos lojistas e pro OTP da plataforma (seção abaixo).

URL é o endereço completo da sua instância Evolution (ex: https://evolution.seudominio.com) e o Token é a chave global de API definida na configuração do servidor Evolution — não é o token de uma instância específica.

WhatsApp — OTP & Recuperação de Senha

Instância Evolution usada pela plataforma para enviar códigos OTP e links de recuperação de senha via WhatsApp.

A URL e o Token são os mesmos configurados acima (Evolution API). Informe aqui apenas o nome da instância conectada ao número da plataforma.

Servidor SMTP (E-mail)

Usado pra enviar códigos OTP, recuperação de senha e avisos de cobrança por e-mail — canal de backup do WhatsApp (se um falhar, o outro ainda entrega).

Com Gmail: use smtp.gmail.com, porta 587, e gere uma Senha de App em myaccount.google.com/apppasswords (a senha normal da conta não funciona aqui). Outros provedores (Outlook, SendGrid, Zoho etc.) seguem o mesmo padrão: host + usuário + senha específica de SMTP.

Google Maps API

Gerar chave no GCP →
Chave usada no cardápio (mapa de localização do cliente) e futuros componentes de endereço. Habilite as APIs Maps JavaScript API e Geocoding API no Google Cloud Console. Se deixar em branco, o sistema usa OpenStreetMap (Leaflet) como fallback gratuito.

Customização PWA

Firebase Cloud Messaging (Push)

Habilita notificações push nativas no navegador e PWA instalado.

Obtenha as credenciais em console.firebase.google.com → Configurações do Projeto → Cloud Messaging.

SMS — Rastreamento (fallback compartilhado)

Função extra do módulo de Rastreamento — reservada como canal alternativo pras empresas desse nicho. Não aparece nem é usada por outros nichos (barbearia, academia etc.). Hoje o envio é manual/sob demanda (não está plugado automaticamente em cobrança ou comandos de bloqueio ainda — isso é próximo passo natural se fizer sentido).

Gateways cadastrados aqui são compartilhados (SHARED) — usados por qualquer empresa de rastreamento que não tenha o próprio gateway configurado. Cada lojista de rastreamento também pode cadastrar um gateway próprio (OWN) em Configurações → Rastreamento; quando existe, ele é tentado primeiro, e o compartilhado daqui entra como reserva.

Prioridade menor = tentado primeiro entre os gateways do mesmo nível. Tipo "Simulado" não envia SMS de verdade — só loga no console, útil pra testar o fluxo sem gastar crédito.
